# Changelog

All notable changes to the **TaskForge** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-21

### Added
- **Core Engine**: Deterministic prompt compilation and cognitive decompression pipeline.
- **Fidelity Verifier**: Cryptographic checksum verification and zero-loss semantic preservation scoring.
- **URL Capsule**: Bidirectional LZ-based state compression for instant workspace sharing.
- **Composio Dispatch**: Webhook integrations for automated agent tool execution.
- **Audio HUD**: Web Audio API synthesized sensory sound cues and haptic feedback.
- **Accessibility Dock**: High contrast toggles, reduced motion mode, and sensory accommodations.
- **Test Suite**: Comprehensive Vitest unit test coverage for contracts, compilers, and scoring engines.
- **UI Workspace**: Next.js 14 App Router cockpit with Tailwind CSS design system.
