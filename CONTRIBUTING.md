# Contributing to TaskForge

Thank you for your interest in contributing to **TaskForge**!

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/manojmulammagari/TaskForge.git
   cd TaskForge
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Development Workflow

- Create a feature branch: `git checkout -b feat/my-new-feature`
- Make your changes and write unit tests where applicable
- Verify test coverage: `npm test`
- Commit your changes using conventional commit messages (`feat:`, `fix:`, `docs:`, `chore:`)
- Push to your branch and open a Pull Request
